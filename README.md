# Кітайска-беларускі транскрыптар (НАН Беларусі 2026)

> **Афіцыйная практычная транскрыпцыя кітайскай мовы сродкамі беларускага алфавіта (Норма 2026)**  
> Канвертацыя кітайскіх іерогліфаў, піньіня і рускай сістэмы Паладыя з аднаўленнем кітайскага напісання.

Вэб-інструмент створаны ў адпаведнасці з нарматыўнай табліцай, ухваленай Вучоным саветам Цэнтра даследаванняў беларускай культуры, мовы і літаратуры НАН Беларусі і Саветам РІКК БДУ, выдадзенай у «Кітайска-беларускім слоўніку» (2026).

---

## Асноўныя магчымасці

1. **З кітайскай мовы (іерогліфы) / піньіня ➔ на беларускую:**
   - Падтрымка спрошчаных і традыцыйных іерогліфаў.
   - Аўтаматычнае вызначэнне піньіня і ўлік поліфаніі (多音字) для складаных слоў і тапонімаў (напрыклад: *Chóngqìng* для 重庆, *Cháng’ān* для 长安).
   - Вывад афіцыйнай беларускай нормы (2026), піньіня з танальнымі знакамі і сістэмы Паладыя для параўнання.
   - Паскладовы / паіерагліфічны разбор (інтэрлінеарны выгляд).

2. **З сістэмы Паладыя ➔ на беларускую і кітайскую:**
   - Распазнаванне і аўтаматычная сегментацыя слоў у сістэме Паладыя (напрыклад: `Бэйцзин`, `Чжуан-цзы`, `Чанъань`, `Сычуань`, `Си Цзиньпин`, `Тяньаньмэнь`, `Хуанхэ`).
   - Дакладная перадача на беларускую мову паводле нормы 2026 года (`Бэйдзін`, `Джуан-дзы`, `Чан’ань`, `Т’еньаньмэнь`).
   - **Узнаўленне кітайскіх іерогліфаў:**
     - Аўтаматычнае супастаўленне са слоўнікам вядомых слоў і тапонімаў (напрыклад: `Бэйцзин` ➔ **北京**, `Чанъань` ➔ **长安**, `Чжуан-цзы` ➔ **庄子**, `Сычуань` ➔ **四川**).
     - **Канструктар іерогліфаў па складах:** магчымасць праглядаць амафоны-кандыдаты для кожнага склада (з тонамі і значэннямі) і выбіраць патрэбны іерогліф у адзін клік.

3. **Зводная нарматыўная табліца складоў:**
   - Поўны даведнік па ўсіх 405 складах.
   - Пошук і фільтры па ініцыялях (b, p, m, f, zh, ch, sh, і г.д.).
   - Супастаўленне: *Піньінь | Беларуская норма 2026 | Сістэма Паладыя | Прыклады іерогліфаў*.

4. **Аўтаномная праца (Zero-dependency):**
   - Усе базы звестак (41 900+ іерогліфаў і поўная табліца складоў) убудаваны непасрэдна ў кліенцкі JavaScript.
   - Працуе без сервера — можна проста адкрыць `index.html` двойчы клікнуўшы ў любым браўзеры.
   - Разгортваецца на **GitHub Pages** без знешніх залежнасцей.

## Як запусціць лакальна

### Варыянт 1: Праз браўзер
Проста двойчы націсніце на файл `index.html` або адкрыйце яго ў Chrome / Firefox / Edge / Safari.

### Варыянт 2: Лакальны сервер Python
```bash
py server.py
# або
python server.py
```
Сервер аўтаматычна адкрые старонку `http://localhost:8000/index.html` у вашым браўзеры.

### Варыянт 3: Кансольная ўтыліта (CLI)
```bash
# Кітайскія іерогліфы
py transcribe.py "北京"
# Вынік:
# Беларуская: бэйдзін
# Піньінь:    Běijīng
# Сістэма Паладыя: бэйцзин

# Піньінь
py transcribe.py "Cháng'ān"
# Вынік: Беларуская: Чан’ань

# З сістэмы Паладыя з аднаўленнем іерогліфаў
py transcribe.py "Чжуан-цзы"
# Вынік:
# Беларуская: Джуан-дзы
# Піньінь:    zhuang-zi
# Іерогліфы:  庄子 (Старажытнакітайскі філосаф)

# Фармат JSON для скрыптоў
py transcribe.py -j "Сычуань"
```

## Тэставанне

У праект уключаны аўтаматычныя тэсты, якія правяраюць:
- 405 нарматыўных складоў паводле Вікіпедыі і слоўніка;
- Правіла стыку складоў з апострафам пасля `-н` перад галоснай;
- Пераўтварэнне з сістэмы Паладыя;
- Аднаўленне кітайскіх іерогліфаў;
- Адпаведнасць рэальным тапонімам («Зводны спіс асноўных кітайскіх тапонімаў»).

Запуск тэстаў:
```bash
py test_transcription.py
```

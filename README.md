# Кітайска-беларускі транскрыптар (НАН Беларусі 2026)

> **Афіцыйная практычная транскрыпцыя кітайскай мовы сродкамі беларускага алфавіта (Норма 2026)**  
> Канвертацыя кітайскіх іерогліфаў, піньіня і рускай паладыцы з аднаўленнем кітайскага напісання.

Вэб-інструмент створаны ў адпаведнасці з нарматыўнай табліцай, ухваленай Вучоным саветам Цэнтра даследаванняў беларускай культуры, мовы і літаратуры НАН Беларусі і Саветам РІКК БДУ, выдадзенай у «Кітайска-беларускім слоўніку» (2026).

---

## 🌟 Асноўныя магчымасці

1. **🇨🇳 Кітайскія словы (іерогліфы) / Піньінь ➔ 🇧🇾 Беларуская транскрыпцыя:**
   - Падтрымка спрошчаных і традыцыйных іерогліфаў.
   - Аўтаматычнае вызначэнне піньіня і ўлік поліфаніі (多音字) для складаных слоў і тапонімаў (напрыклад: *Chóngqìng* для 重庆, *Cháng’ān* для 长安).
   - Вывад афіцыйнай беларускай нормы (2026), піньіня з танальнымі знакамі і традыцыйнай рускай паладыцы для параўнання.
   - Паскладовы / паіерагліфічны разбор (інтэрлінеарны выгляд з падказкамі).

2. **📜 Руская транскрыпцыя (сістэма Паладыя) ➔ 🇧🇾 Беларуская + 🀄 Кітайскія іерогліфы:**
   - Распазнаванне і аўтаматычная сегментацыя рускіх паладыеўскіх складоў (напрыклад: `Бэйцзин`, `Чжуан-цзы`, `Чанъань`, `Сычуань`, `Си Цзиньпин`, `Тяньаньмэнь`, `Хуанхэ`).
   - Дакладная перадача на беларускую мову паводле нормы 2026 года (`Бэйдзін`, `Джуан-дзы`, `Чан’ань`, `Т’еньаньмэнь`).
   - **Узнаўленне кітайскіх іерогліфаў:**
     - Аўтаматычнае супастаўленне са слоўнікам вядомых слоў і тапонімаў (напрыклад: `Бэйцзин` ➔ **北京**, `Чанъань` ➔ **长安**, `Чжуан-цзы` ➔ **庄子**, `Сычуань` ➔ **四川**).
     - **Інтэрактыўны канструктар іерогліфаў па складах:** магчымасць праглядаць амафоны-кандыдаты для кожнага склада (з тонамі і значэннямі) і выбіраць патрэбны іерогліф у адзін клік.

3. **📖 Зводная нарматыўная табліца ўсіх складоў:**
   - Поўны даведнік па ўсіх 405 складах.
   - Жывы пошук і фільтры па ініцыялях (b, p, m, f, zh, ch, sh, і г.д.).
   - Супастаўленне: *Піньінь | Беларуская норма 2026 | Паладыца | Прыклады іерогліфаў*.

4. **🚀 Цалкам аўтаномная праца (Zero-dependency):**
   - Усе базы звестак (41 900+ іерогліфаў і поўная табліца складоў) убудаваны непасрэдна ў кліенцкі JavaScript.
   - Працуе без сервера — можна проста адкрыць `index.html` двойчы клікнуўшы ў любым браўзеры.
   - Ідэальна пасуе для бясплатнага размяшчэння на **GitHub Pages**!

## 🚀 Як запусціць лакальна

### Варыянт 1: Без аніякай усталёўкі (праз браўзер)
Проста двойчы націсніце на файл `index.html` або адкрыйце яго ў Chrome / Firefox / Edge / Safari.

### Варыянт 2: Лакальны сервер Python
Калі хочаце запусціць як паўнавартасны лакальны вэб-сэрвіс:
```bash
py server.py
# або
python server.py
```
Сервер аўтаматычна адкрые старонку `http://localhost:8000/index.html` у вашым браўзеры.

### Варыянт 3: Кансольная ўтыліта (CLI)
Для хуткай транскрыпцыі з каманднага радка:
```bash
# Кітайскія іерогліфы
py transcribe.py "北京"
# Вынік:
# Беларуская: бэйдзін
# Піньінь:    Běijīng
# Паладыца:   бэйцзин

# Піньінь
py transcribe.py "Cháng'ān"
# Вынік: Беларуская: Чан’ань

# З рускай паладыцы з аднаўленнем іерогліфаў
py transcribe.py "Чжуан-цзы"
# Вынік:
# Беларуская: Джуан-дзы
# Піньінь:    zhuang-zi
# Іерогліфы:  庄子 (Старажытнакітайскі філосаф)

# Фармат JSON для скрыптоў
py transcribe.py -j "Сычуань"
```

## 🌐 Як апублікаваць на сваім акаўнце GitHub (GitHub Pages)

Паколькі вы маеце акаўнт на GitHub, вы можаце зрабіць гэты сэрвіс публічна даступным у інтэрнэце за 1 хвіліну:

1. **Стварыце новы рэпазіторый на GitHub:**
   - Зайдзіце на [github.com/new](https://github.com/new).
   - Назавіце рэпазіторый, напрыклад, `kitaj-bielarus-transkrypcyja` (ці любую іншую назву).
   - Зрабіце яго **Public**.

2. **Загрузіце файлы ў рэпазіторый:**
   Адкрыйце тэрмінал у папцы праекта і выканайце:
   ```bash
   git init
   git add .
   git commit -m "Першы рэліз кітайска-беларускага транскрыптара"
   git branch -M main
   git remote add origin https://github.com/<ваш-нікнейм>/kitaj-bielarus-transkrypcyja.git
   git push -u origin main
   ```

3. **Уключыце GitHub Pages:**
   - У вашым рэпазіторыі на GitHub адкрыйце ўкладку **Settings** (Налады).
   - Злева ў меню выберыце **Pages**.
   - У раздзеле **Build and deployment**:
     - *Source*: выберыце **Deploy from a branch**.
     - *Branch*: выберыце **main**, папка **/(root)** і націсніце **Save**.
   - Праз некалькі секунд ваш сайт будзе даступны анлайн па адрасе:  
     `https://<ваш-нікнейм>.github.io/kitaj-bielarus-transkrypcyja/`!
